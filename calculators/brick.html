Brick Calculator

Calculate exactly how many bricks to order for any wall, garden border, or masonry project, including waste allowance.

How It Works

Uses standard US brick count of ~6.75 bricks per sq ft (3/8" mortar, running bond), then applies waste factor.

Formula

Bricks = Wall Area × 6.75 bricks/sq ft × (1 + Waste%)

Example

10×5 ft wall, 10% waste:
50 sq ft × 6.75 × 1.10 = 371 bricks

When to Use This Calculator

Use when building garden walls, planters, fireplace surrounds, or any brick masonry project.

Common Mistakes to Avoid

  • Forgetting mortar joints — installed brick takes up more space than bare dimensions.
  • Ordering exact count — breakage and cuts require extra.
  • Mixing brick batches — slight color differences between batches cause alignment problems.

Frequently Asked Questions

Bricks per sq ft?
Standard US modular brick in running bond with 3/8" mortar: ~6.75 bricks/sq ft.
Mortar type?
Type S for exterior/below-grade; Type N for interior/above-grade exterior.
Mortar cure time?
24–48 hours workable strength; full cure in 28 days.
Need sealer?
Most outdoor brick benefits from penetrating masonry sealer in freeze-thaw climates.
