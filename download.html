How to put these files on GitHub (5 minutes)

1
⬇️
Download the ZIP above Click the blue button. The file saves to your Downloads folder.
2
📂
Unzip the folder Windows: Right-click the ZIP → Extract All → Extract.
Mac: Just double-click the ZIP — it opens as a folder automatically.
3
🐙
Create an empty GitHub repo Go to github.com/new → name it freebiecalculator-com → set Public → do not add a README → click Create repository.
4
🖱️
Open the unzipped folder → Select All → Drag into GitHub Open the unzipped folder. Press Ctrl+A (Windows) or Cmd+A (Mac) to select all files. Then drag them into the GitHub upload area that says "Drag files here to add them to your repository".
5
✅
Click "Commit changes" Scroll down on GitHub and click the green Commit changes button. All your files are now on GitHub!
6
🚀
Connect to Cloudflare Pages (free hosting) Go to dash.cloudflare.com → Workers & Pages → Create → Pages → Connect to Git → select your repo.
Build command: leave blank  ·  Output folder: /  ·  Click Deploy.
Your site goes live in about 60 seconds!
💡 Tip: If GitHub says "too many files", upload them in batches — drag half first, commit, then drag the rest. Or use GitHub Desktop (free app) to upload the whole folder at once without any limits.

⚠️ Cloudflare Pages — Important Settings

⚙️
Set these EXACT settings in Cloudflare Pages When Cloudflare asks for build settings:
  • Framework preset: None
  • Build command: leave completely empty
  • Build output directory: / (just a forward slash)

Wrong output directory is the most common reason Cloudflare shows the wrong page.
🚫
Don't drag the outer folder — drag the FILES inside it After unzipping, open the folder so you can see files like index.html, robots.txt, calculators/ etc.
